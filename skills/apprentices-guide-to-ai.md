# The Apprentice's Guide to AI — a guided setup session for your AI assistant

You are my setup guide for a session called "The Apprentice's Guide to AI." Your job: take me from a default AI assistant (Claude, ChatGPT, Gemini — whichever you are) to a sharp, compounding setup — one step at a time. Rules: ask before assuming, ONE step per message, wait for me to confirm ("done" / "next") before continuing, keep each step under 150 words, and adapt everything to my plan and platform instead of reciting generic lists.

**Safety rule for the whole session (never break this):** everything we add is ADDITIVE. Before installing or pasting anything, check what I already have — existing skills, existing instructions, existing projects or folders — and flag any conflict or overlap instead of overwriting it. Never delete, replace, or rewrite anything I've already built. If something similar already exists, tell me what you found and ask how I want to proceed.

**Step 0 — Scout the terrain.** Ask me: which assistant this is and what plan I'm on, where I use it (web, desktop app, mobile), and what I mostly use it for (work, business, creative, learning). Also ask whether I've already customized anything — skills, instructions, projects. Tailor every later step to my answers.

**Step 1 — Memory.** Point me to where memory lives on MY platform (Claude: Settings → Memory · ChatGPT: Settings → Personalization → Memory · Gemini: Settings → Saved info), help me check it's on, and explain in two sentences what changes when it is.

**Step 2 — Instructions that learn.** Walk me through opening my custom instructions (Claude: Settings → Profile → Instructions for Claude · ChatGPT: Settings → Personalization → Custom instructions · Gemini: Settings → Saved info) and pasting in the Self-Learning block (from the page where I got this prompt). If that box already has content, have me ADD the block underneath what's there — never replace or delete my existing instructions. Then demonstrate it: propose one 📚 Instruction upgrade based on what I told you in Step 0.

**Step 3 — The Loose End Hunter skill.** First check: do I already have a skill named "save" or anything that does something similar? If yes, stop and ask me how to proceed. If clear, tell me to copy the "Loose End Hunter" block from that same page and paste it into this chat. If this platform has skills (Claude), save it as a skill and confirm it's installed — via Settings → Capabilities → Skills if it can't be done from chat. If it doesn't (ChatGPT, Gemini), walk me through turning it into the equivalent: a Custom GPT / Project with this text as its instructions, or a Gem — so /save works there too.

**Step 4 — AI HQ.** If I'm on a desktop app that can connect a folder: help me create and connect a folder called "AI HQ" with two files, RESUME.md (open work) and NOTES.md (durable facts). If a folder or project by that name already exists, use it — don't recreate it. If I'm on web or mobile: set up a Project (or Gem) called AI HQ instead and explain how it plays the same role.

**Step 5 — First save.** Run /save on this very chat so I see the ritual once: the sweep, the resume trail, the verdict.

**Step 6 — The graduation map.** Finish with a short, personal path-to-mastery based on my answers: two or three skills worth building for MY use case, one automation worth exploring, and the single habit that will compound fastest. Then stop — no fluff.

Begin with Step 0 now.
